# 小批次等效大批次：演化策略梯度估计的数学分析

> 背景：HyperscaleES 实验（`snn_es_mnist_experiment.md` 7.7/7.10/10 节）表明演化策略（ES）的
> 学习能力主要靠**扩大并行批次**放大——8×4090 上 batch=60000 达 91.5%，而小批次几乎不学习。
> 本文从数学上回答：**在小批次显存受限时，如何让小批次训练"等效于"大批次训练**，并用
> Python 数值验证（`pythonScript/exp_small_batch_equiv.py`）。

---

## 1. 问题定义：大批次为什么好

HyperscaleES 的演化更新（EggRoll noiser）本质是 ES 梯度估计器：

```
ĝ_N = (1/N) · Σ_{i=1}^{N} f(x + σ·εᵢ) · εᵢ / σ        (1)
```

其中 εᵢ ~ N(0, I) 为扰动方向，f 为 fitness，N 为并行样本数（batch）。

**大批次优势的唯一来源是方差**：蒙特卡洛估计的方差随样本数按 1/N 衰减（1/N 律），
大批次的梯度估计信噪比更高 → 更新方向更接近真实梯度 → 学习更快。

**"等效"的数学定义**：若某技巧把小批次 N_s 的梯度估计方差压缩 F 倍，则它在梯度噪声
意义上"等效于"批次 N_eff = F·N_s 的大批次。目标即最大化 F。

---

## 2. 方差结构的解析推导

对 fitness 做一阶展开 f(x + σε) ≈ f(x) + σεᵀ∇f + O(σ²)，代入 (1) 得：

```
ĝ_N ≈ (f(x)/σ)·(1/N)Σ εᵢ  +  (1/N)Σ (εᵢᵀ∇f)·εᵢ            (2)
      └──── 基线项 ────┘   └──────── 梯度项 ────────┘
```

- **基线项**：均值为 0，每分量方差 ≈ f(x)²/σ²。它不携带任何梯度信息，纯粹是 fitness
  绝对尺度 f(x) 与扰动幅度 σ 之比引入的噪声。f(x) 越大（如 MNIST 的 log-likelihood 累加值）
  或 σ 越小，该项越致命。
- **梯度项**：均值为 ∇f（对高斯，E[(εᵀ∇f)ε] = ∇f），每分量方差 ≈ (d+1)‖∇f‖²/N，
  其中 d 为参数维度——**高维惩罚**。这正是 ES 在高维（如 fc1 满秩 784×128）上样本效率
  极低的原因（docs 7.5.2 ⑤：满秩 ES 崩溃）。

**总方差**：

```
Var(ĝ_N) = Var[f(x)·ε/σ] + Var[(εᵀ∇f)·ε]  ≈  d·f(x)²/σ² + (d+1)‖∇f‖²   (每分量，再 ÷N)
```

两者都 ∝ 1/N，且都随维度 d 增长。结论：**维度一定时，方差只能靠增大 N 或方差缩减技巧压降**。

---

## 3. 四种"小批次等效大批次"的数学手段

### 3.1 基线/中心化（baseline subtraction，对应 EggRoll 的 z-score）

减去均值后，估计器变为：

```
ĝ = (1/N) Σ (fᵢ - f̄) · εᵢ / σ
```

f̄ ≈ E[f(x+σε)] ≈ f(x) 的波动恰好抵消（2）式的**基线项**，方差中 f(x)²/σ² 项被消除，
剩余仅梯度项（及高阶曲率项）。实现零成本：EggRoll 的 `convert_fitnesses` 已做 z-score 归一化。

### 3.2 对偶采样（antithetic sampling，EggRoll 已内置）

对偶对 (ε, -ε) 成对评估：

```
ĝ = (1/(N/2)) Σ [f(x+σεᵢ) - f(x-σεᵢ)] · εᵢ / (2σ)
```

f(x+σε) - f(x-σε) = 2σεᵀ∇f + O(σ³)——**基线项精确对消**，且偶次（曲率）项也相消。
代价是独立方向数减半（N/2 对），对纯梯度项略吃亏，但基线项（往往占主导）被彻底消除。
EggRoll 通过奇偶 thread_id 取 ±σ 实现（`get_lora_update_params`：`true_thread_idx = thread_id // 2`）。

### 3.3 梯度累积（gradient accumulation）——**精确等价** ⭐

参数**冻结**在 x，把 N_L 个样本切成 K 个 chunk（各 N_s 个，用不同噪声），每 chunk 计算
原始梯度后平均，再做一次更新：

```
ĝ_acc = (1/K) Σ_k [ (1/N_s) Σ_{i∈chunk_k} (fᵢ - f̄)εᵢ/σ ]
      = (1/(K·N_s)) Σ_{i=1}^{K·N_s} (fᵢ - f̄)εᵢ/σ
      = ĝ_{K·N_s}                                          ← 与单个大批次完全同一估计器
```

**求和交换律保证精确相等**（对同一参数点 x），方差 = σ²/(K·N_s) = 大批次方差。
显存只需 N_s 而非 N_L。这是显存受限场景下**零信息损失**的等效手段。

### 3.4 回归式 / guided ES（OLS 代理，最小方差估计）——**最强缩减**

用 N 个样本拟合线性代理 f(x+σεᵢ) ≈ a + bᵀεᵢ（最小二乘），取回归系数为梯度估计：

```
ĝ_reg = b/σ
```

- 由 **Gauss-Markov 定理**：对"线性于 ε"的部分，OLS 系数是所有线性无偏估计中**方差最小**的；
- 方差 ∝ 残差方差/N，而非基线项或 (d+1)‖∇f‖²/N——当 fitness 对噪声近似线性时，
  缩减可达数百到数千倍（数值验证见第 5 节）；
- 代价：需做一次线性回归（对 LoRA 场景是逐层小规模 lstsq），且代理模型非线性时增益收窄。

---

## 4. 等效条件小结

| 手段 | 方差缩减机制 | 等效批次 N_eff | 实现成本 | 是否精确 |
|---|---|---|---|---|
| 基线/中心化 | 消除 f(x)²/σ² 项 | N·F₁ | 零（已内置） | 否（残差仍在） |
| 对偶采样 | 基线项 + 偶次项对消 | N·F₂ | 零（已内置） | 否 |
| 梯度累积 | 求和平均（1/N 律） | K·N_s（**精确**） | 脚本层改动 | **是** |
| 回归式 ES | OLS 最小方差 | N·F₃（最大） | 更新逻辑改动 | 否 |

> 注意：**单纯"小批次 + 多跑 epoch"不构成等效**。方差只能由 N 或上述技巧压降；
> 多 epoch 是重复用已用过的噪声方向，不增加每步梯度估计的信息量（docs 7.4 平台期的成因）。

## 5. Python 数值验证（`pythonScript/exp_small_batch_equiv.py`）

**实验设置**：d=64、σ=0.2、二次 fitness f(x) = -½‖x - x*‖²（最大点在 x*），x0 处 ‖∇f‖≈6.6。

### 5.1 1/N 律验证

| N | Var(ĝ) | Var·N |
|---|---:|---:|
| 50 | 17511 | 875552 |
| 100 | 8797 | 879683 |
| 200 | 4337 | 867443 |
| 400 | 2160 | 864040 |
| 800 | 1120 | 895819 |

Var·N ≈ 8.6e5~9.0e5 近似恒定 → **方差 ∝ 1/N 律成立** ✓

### 5.2 四种手段的方差缩减与等效批次倍数（N=200，reps=2000）

| 手段 | Var(ĝ) | 等效批次倍数 F |
|---|---:|---:|
| vanilla（原始） | 4434.7 | 1.0× |
| baseline（减均值） | 14.6 | **303×** |
| antithetic（对偶对） | 28.5 | **156×** |
| regression（回归式 ES） | 0.62 | **7115×** |

→ 在理想二次面上：小批次 200 + 回归式 ES ≈ 大批次 1.4M 的梯度噪声水平。

### 5.3 梯度累积 = 大批次（精确等价验证，reps=500）

| 累积配置 | Var(累积) | Var(单批带基线) | Var(单批无基线) |
|---|---:|---:|---:|
| 100×6 = 600 | 4.90 | 4.92 | 1459 |
| 200×4 = 800 | 3.66 | 3.69 | 1075 |
| 50×10 = 500 | 5.86 | 5.88 | 1726 |

累积与单批带基线**几乎完全一致**（<1% 差异）→ 精确等价 ✓；无基线差 300 倍 → 累积必须配合中心化。

### 5.4 固定样本预算（S=40 万）的优化轨迹

| 策略 | 最终 ‖x-x*‖（起点 ~6.5） |
|---|---:|
| 大批次 N=2000（200 步） | 0.118 |
| 小批次 N=100（4000 步） | 0.107 |
| 小批次 + 对偶 N=100 | **0.000** |
| 小批次 + 回归 N=100 | 0.169 |

→ 平滑凸面上小批次+多步 ≈ 大批次+少步（经典 SGD 结论）；对偶在二次面上收敛最彻底。

## 6. 结论与落地建议

1. **数学本质**：大批次优于小批次 = 梯度估计方差 ∝ 1/N（含基线项与 d 维惩罚两项）。
   等效 = 用方差缩减技巧把 N_eff = F·N 抬到大批次水平。

2. **零成本已生效**：HyperscaleES/EggRoll 已内置 **z-score 基线**（`convert_fitnesses`）与
   **对偶采样**（奇偶 thread_id ±σ），即 vanilla 的 4434 级方差已压到 ~15~28 级。

3. **最实用**：**梯度累积**——脚本层冻结参数、K 个 chunk 各算梯度后一次更新，与大批次
   **精确等价**、显存只占 1/K。8×48GB 下 batch=48000 可模拟 192000（或 60000→240000）。

4. **潜力最大**：**回归式 ES**——OLS 系数为最小方差线性无偏估计，理想面 7000× 缩减；
   需把 EggRoll 的 einsum 更新换成逐层 lstsq，真实 SNN 增益待实测（预期显著但低于理想面）。

5. **局限**：以上倍数基于理想二次面；真实 SNN 非凸 + 泊松编码噪声 + 稀疏硬奖励会压缩
   缩减幅度。且**方差缩减不改变探索方向数**——若瓶颈是低秩子空间表达力（docs 7.11），
   仍需靠 rank/容量而非批次技巧。
